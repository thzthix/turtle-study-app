# Turtle Study App

따뜻한 일러스트 감성의 거북이 동행형 집중 앱입니다.

사용자가 집중 세션을 시작하면 거북이가 길을 걷기 시작하고, 세션 중간에는 짧은 돌봄 상호작용이 나타납니다. 사용자가 세션을 잘 마치면 거북이가 애교와 보상으로 답해주는 구조를 목표로 합니다.

## 현재 단계

현재는 Phase 1 웹 MVP를 설계하고 구현하는 단계입니다.

이번 단계에서 집중하는 범위:

- 웹 기반 집중 세션 MVP
- 거북이 동행 경험과 감성형 UI
- 짧은 돌봄 상호작용
- 세션 완료 보상
- 가벼운 소셜 경쟁/응원 콘셉트의 첫 화면 표현

이번 단계에서 하지 않는 것:

- 로그인
- 서버 연동
- 실시간 멀티플레이
- 결제
- 푸시 알림
- 네이티브 앱 배포
