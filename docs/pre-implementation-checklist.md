# Pre-Implementation Checklist

## 목적

이 체크리스트는 handoff 문서가 준비되기 전에 구현이 앞질러 나가는 것을 막기 위한 검증용이다.

---

## 1. 기준 소스 확인

- `1.19.02`를 거북이 상태 기준으로 사용한다고 명시했는가
- `1.10.17`을 장면 구조와 등껍질 기준으로 사용한다고 명시했는가
- 두 기준의 역할이 문서마다 충돌하지 않는가

## 2. 자산 분리 구조 확인

- `background-scene` 범위가 명확한가
- `scene-objects`가 독립 자산 목록으로 정의되어 있는가
- `turtle-states`가 walking/resting/cheerful로 고정되어 있는가
- `ui-overlays`가 별도 층으로 분리되어 있는가
- tokens 문서 또는 파일이 존재하는가

## 3. 시안 유사도 원칙 확인

- 새 스타일 제안이 문서에 섞여 있지 않은가
- 더 예쁘게 보이기 위한 재해석 문장이 없는가
- 거북이를 새 캐릭터처럼 다루는 표현이 없는가
- flat icon식 단순화 허용 문장이 없는가

## 4. UI 규칙 확인

- 시간 설정이 팝업으로 정의되어 있는가
- 집중 HUD가 작고 얇은 pill형으로 정의되어 있는가
- care moments가 아이콘 중심으로 정의되어 있는가
- 완료 오버레이가 조용한 축하 톤으로 정의되어 있는가
- 큰 카드형 생산성 레이아웃 금지가 문서에 반영되어 있는가

## 5. 구현 보류 조건 확인

- 자산 승인 전 메인 화면 반영을 시작하지 않는다고 적혀 있는가
- 기존 재해석 자산이 final 기준에서 제외되었는가
- 구현보다 handoff 정리가 먼저라는 점이 분명한가

## 6. PR 준비 확인

- PR 목적이 `handoff 기준 정리` 하나로 좁혀져 있는가
- 구현 일기에 설계 판단과 제외 기준이 남아 있는가
- 커밋 메시지가 한국어인가
- 사용자 승인 없이 머지하지 않는다고 전제되어 있는가
