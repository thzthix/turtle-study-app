# Reference Design Reapply

## 목적

이 문서는 승인된 시안 이미지를 구현에 다시 정확히 반영하기 위한 기준 문서다.

이번 반복에서는 `내 해석으로 다시 그리기`를 금지한다.
먼저 시안과 최대한 비슷한 자산을 만들고, 구현은 그 자산을 배치하는 수준에서 시작한다.

---

## 이번에 잘못된 점

- 거북이를 시안 기반 자산으로 쓰지 않고 새 캐릭터처럼 다시 그렸다.
- 질감이 `수채화+파스텔`이 아니라 `평면 SVG` 느낌으로 바뀌었다.
- 머리, 몸, 표정 비율이 시안과 달라졌다.
- 걷는 모습, 쉬는 모습, 기분 좋은 모습이 같은 캐릭터의 상태 변화처럼 보이지 않았다.

---

## 절대 유지할 것

### 1. 같은 캐릭터여야 한다

- 걷는 모습
- 쉬는 모습
- 기분 좋은 모습

이 세 상태는 서로 다른 거북이가 아니라 **같은 거북이의 상태 변화**처럼 보여야 한다.

### 2. 형태 비율

- 머리는 둥글고 크지만 과장되게 크지 않다
- 몸통은 낮고 안정적이다
- 등껍질은 둥근 반구형에 가깝다
- 다리는 짧고 통통하다
- 꼬리는 매우 작다

### 3. 질감

- 깨끗한 벡터보다 `종이 질감`, `분필`, `파스텔`, `수채화 번짐` 쪽에 가깝다
- 채도는 낮고 밝다
- 경계선은 딱딱한 검은 라인 대신 부드럽게 처리한다

### 4. 표정

- 눈은 작은 점 또는 부드러운 감은 선
- 입은 짧고 둥글다
- 볼은 은은한 분홍
- cheerful 상태만 입을 조금 더 열 수 있다

---

## 상태별 기준

### walking

- 머리를 들고 천천히 앞을 본다
- 앞다리와 뒷다리가 살짝 교차된 자세
- 표정은 안정적이고 부드럽다
- 걷는다고 해서 몸이 크게 튀면 안 된다

### resting

- 고개를 낮추고 바닥 가까이에 둔다
- 눈을 감는다
- 몸 전체가 낮아진 느낌이어야 한다
- 쉰다고 해서 다른 캐릭터처럼 변하면 안 된다

### cheerful

- walking 자세를 기본으로 한다
- 머리를 조금 들고 표정만 더 밝아진다
- 입을 열고 하트나 햇살 표시가 붙어도 된다
- 실루엣 자체는 walking과 크게 다르지 않아야 한다

---

## 구현 원칙

- 각 상태는 별도 자산으로 저장한다
- 구현 단계에서는 CSS로 몸통 형태를 다시 만들지 않는다
- 걷기 애니메이션은 `위치 이동 + 두 프레임 교차`까지만 허용한다
- 몸통 상하 흔들림은 2~3px 이하
- 머리 움직임은 1~2px 이하

---

## final 기준 제외 대상

- 시안보다 단순화된 turtle SVG 재해석본
- 시안보다 플랫한 background SVG 재해석본
- 시안을 참고해 새로 그린 유사 보드 이미지
- 캐릭터와 장면을 CSS 도형으로 다시 조합하는 방식
