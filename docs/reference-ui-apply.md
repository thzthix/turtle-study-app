# Reference UI Apply

## 목적

거북이와 배경 자산만 맞추는 것으로 끝내지 않고,
승인된 시안의 UI concept까지 구현 기준으로 고정한다.

이번 문서는 아래를 정리한다.

- 시간 선택 팝업
- 집중 중 HUD
- care moments UI
- 완료 후 오버레이 톤
- 장면 위 안전 영역

---

## 전체 원칙

- UI는 장면보다 앞에 나오면 안 된다.
- 화면의 주인공은 항상 `배경 + 길 + 거북이`다.
- UI는 `작고 조용한 오버레이`로 올라간다.
- 카드 앱처럼 보이는 큰 박스형 레이아웃은 피한다.
- 큰 대시보드형 패널은 금지한다.

---

## 1. 시간 선택 팝업

기준 시안:

- `1.19.02.svg` 하단 왼쪽 `시간 선택 팝업`

구성:

1. 제목: `집중할 시간을 선택해요`
2. 원형 시간 버튼 5개
3. 하단 메인 CTA: `시작하기`
4. 하단 장식: 꽃, 작은 거북이

반영 규칙:

- 메인 카드가 아니라 `중앙 팝업`으로 연다
- 시간 버튼은 `동그란 칩`처럼 보이게 한다
- 선택된 버튼만 초록 포인트로 강조한다
- CTA는 하나만 둔다
- 닫기 버튼은 우측 상단에 작게 둔다

하지 말 것:

- 설명 문구를 길게 넣기
- 보조 버튼을 크게 두기
- 카드형 정보 패널처럼 키우기

---

## 2. 집중 중 HUD

기준 시안:

- `1.19.02.svg` 하단 중앙 `집중 중 HUD (최소)`

구성:

1. 작은 잎 아이콘
2. 남은 시간
3. 우측 원형 버튼

반영 규칙:

- pill형 바 형태
- 한 줄 구조
- 정보는 최소만 유지
- 길과 거북이를 가리지 않는 위치에 둔다

우선 위치:

- 상단 중앙

대안 위치:

- 하단 좌측

하지 말 것:

- 진행 메시지를 크게 노출
- 버튼 2~3개를 한 번에 크게 노출
- 별도 큰 카드 패널로 확장

---

## 3. Care Moments

기준 시안:

- `1.10.17.svg` 하단 왼쪽 `care moments`

구성:

1. 짧은 제목
2. 물 아이콘 버튼
3. 당근 아이콘 버튼

반영 규칙:

- 카드처럼 두껍게 만들지 않는다
- 버튼은 둥근 아이콘 중심
- 레이블은 짧게
- 필요할 때만 뜬다

추천 카피:

- `잠깐 돌봐주세요`
- `물 주기`
- `당근 주기`

---

## 4. 완료 후 오버레이

기준 방향:

- 장면을 지우지 않고, 조용한 축하 반응만 올린다

반영 규칙:

- 거북이의 cheerful 상태 유지
- 작은 축하 말풍선 또는 badge 정도만 허용
- 배경은 계속 보여야 한다
- 결과 요약은 아래쪽 보조 영역으로 밀어낸다

하지 말 것:

- 승리 카드처럼 화면을 다 덮기
- 과한 burst 효과
- 너무 큰 통계 패널

---

## 5. 장면 위 안전 영역

### 좌상단

- 말풍선 가능
- 너무 큰 카드 금지

### 상단 중앙

- HUD 가능

### 우측 상단

- 닫기/설정류 버튼 가능

### 하단 중앙

- 진행 캡션 가능

### 하단 좌우

- care moments 또는 작은 보조 UI 가능

길과 거북이 위는 최대한 비운다.

---

## 구현 우선순위

1. 시간 선택 팝업을 시안형으로 맞춘다
2. HUD를 더 작게 줄인다
3. care moments를 아이콘형으로 줄인다
4. 완료 후 오버레이를 조용하게 정리한다

---

## 결론

UI도 자산만큼 중요하지만,
이 프로젝트에서는 UI가 주인공이 아니라 배경과 거북이를 받쳐주는 조용한 층이어야 한다.

---

## final 기준 제외 대상

- 화면 하단을 크게 차지하는 카드형 요약 패널
- 장면보다 먼저 읽히는 생산성 대시보드
- 거북이보다 UI가 더 강하게 느껴지는 패널 구조
