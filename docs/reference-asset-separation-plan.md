# Reference Asset Separation Plan

## 목적

주어진 두 SVG를 기준으로, 실제 구현에 사용할 자산을 어떻게 분리할지 정리한다.

이번 계획의 핵심은 아래다.

- `1.19.02.svg`는 거북이 상태와 표정 기준
- `1.10.17.svg`는 실제 앱 장면과 등껍질 디테일 기준
- 두 파일을 섞되, 기준 우선순위는 명확히 둔다

---

## 소스 파일 역할

### 1. `1.19.02.svg`

역할:

- 걷는 모습
- 쉬는 모습
- 기분 좋은 모습

강점:

- 상태 3개가 한 보드에 있어 비교하기 좋다
- 표정 차이가 명확하다
- 같은 캐릭터의 상태 변화로 읽기 쉽다

약점:

- 등껍질 무늬와 질감이 메인 장면 쪽보다 단순하게 보인다
- 실제 앱 장면 속 거북이보다 일부 디테일이 약하다

결론:

- `얼굴`, `자세`, `상태 차이`는 이 파일을 기준으로 쓴다

### 2. `1.10.17.svg`

역할:

- 메인 배경 장면
- 길 위 오브젝트 배치
- 실제 앱 mockup 구조
- 배경 mockup 안의 거북이 디테일, 특히 등껍질 무늬 참고

강점:

- 앱에 들어갈 실제 장면 구조가 보인다
- 등껍질 무늬와 배경 톤이 더 풍부하다
- 길, 물그릇, 당근, 표지판, 도착 깃발 위치가 실제 서비스에 가깝다

약점:

- 파일 규모가 크고 path가 많아 직접 재사용은 어렵다
- 거북이 상태별 분리용 파일로는 적합하지 않다

결론:

- `등껍질`, `색감`, `배경`, `장면 구성`은 이 파일을 기준으로 쓴다

## 기준 우선순위

### 거북이 얼굴과 상태

우선 기준: `1.19.02.svg`

- walking의 표정과 머리 위치
- resting의 눈 감은 표정과 낮은 자세
- cheerful의 열린 입과 밝은 반응

### 거북이 등껍질

우선 기준: `1.10.17.svg`의 background mockup

- 등껍질 외곽 비율
- 등껍질 무늬 밀도
- 무늬의 부드러운 굴곡
- 질감과 색 차이

### 배경 장면

우선 기준: `1.10.17.svg`

- 전체 가로형 풍경
- 길 흐름
- 체크포인트 오브젝트
- UI가 올라갈 수 있는 안전 영역

## 분리할 최종 자산

이번에 최종적으로 분리해야 하는 자산은 아래다.

중요:

- 이 문서는 `무엇을 분리해야 하는지`를 정하는 문서다.
- 현재 레포 안에 존재하는 재해석 자산을 승인 자산으로 인정하는 문서가 아니다.

### 캐릭터 자산

1. `turtle-walking`
2. `turtle-resting`
3. `turtle-cheerful`

규칙:

- 3개 모두 같은 거북이처럼 보여야 한다
- 등껍질은 세 파일 모두 동일한 무늬 체계를 공유한다
- 상태 차이는 얼굴, 목 각도, 다리 배치, 자세 높이로만 만든다

### 배경 자산

4. `background-scene`

규칙:

- 메인 풍경 전체
- 길과 자연 요소 포함
- UI 얹기 좋은 여백 유지

### 선택 자산

5. `scene-water-bowl`
6. `scene-carrot`
7. `scene-sign-start`
8. `scene-sign-arrow`
9. `scene-flag-finish`

이건 필요하면 배경에서 분리해서 독립 오브젝트로 쓴다.

## 거북이 재구성 규칙

### 공통 구조

모든 상태가 아래 공통 구조를 공유해야 한다.

1. 머리
2. 목/몸통
3. 등껍질
4. 앞다리 2개
5. 뒷다리 2개
6. 꼬리
7. 바닥 그림자

### 상태별 차이 허용 범위

#### walking

- 머리를 든다
- 앞/뒷다리가 약간 교차된다
- 눈은 뜬다
- 입은 닫힌 미소

#### resting

- 머리를 낮춘다
- 몸 전체가 낮아진다
- 눈은 감는다
- 다리는 몸에 더 붙는다

#### cheerful

- walking 자세를 기본으로 한다
- 머리를 약간 더 든다
- 입을 열 수 있다
- 하트/빛 표시 추가 가능

### 상태별 차이 금지 범위

- 머리 크기 급변 금지
- 등껍질 모양 변경 금지
- 다리 길이 변경 금지
- 꼬리 위치 급변 금지
- 전혀 다른 채색 금지

## 등껍질 재현 규칙

등껍질은 `1.10.17.svg background mockup`을 우선 참고한다.

반영해야 할 요소:

- 반구형 실루엣
- 너무 날카롭지 않은 그리드형 무늬
- 무늬 간격이 너무 촘촘하지 않음
- 위에서 아래로 은은하게 깊이 차이
- flat stroke가 아니라 부드러운 톤 차이

반영하지 말아야 할 요소:

- 딱딱한 진한 outline
- 기하학적으로 너무 정확한 육각형 느낌
- 일반 아이콘처럼 단순화된 무늬

## final 기준 제외 대상

아래는 현재 분리 계획의 승인 결과물이 아니다.

- 시안 재해석 기반의 배경 SVG 초안
- 시안 재해석 기반의 turtle SVG 초안
- 장면과 관계없는 handoff 데모 화면 구현

이유:

- 세션 진행에 따라 강조하거나 애니메이션할 수 있다
- 위치는 고정하되 상태 연출은 따로 줄 수 있다

---

## 구현 연결 순서

1. 거북이 3상태 SVG를 먼저 정확히 만든다
2. 배경 자산을 정리한다
3. 그 다음 메인 화면에 배경을 실제로 깐다
4. 거북이는 이미지 자산으로 얹는다
5. 걷기 애니메이션은 `위치 이동 + 상태 전환`부터 적용한다
6. 상하 흔들림은 마지막에 최소 진폭으로 추가한다
