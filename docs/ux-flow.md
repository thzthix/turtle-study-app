# UX Flow

## 1. 화면 구성

MVP는 아래 4개 화면 블록으로 구성한다.

1. 홈
2. 집중 세션
3. 세션 완료
4. 친구 거북이 보드

한 페이지 안에서 섹션처럼 구성해도 되고, 단계 전환형 인터페이스로 풀어도 된다.

## 2. 홈 화면

### 목적

- 제품 콘셉트를 바로 이해시킨다.
- 세션 시작 진입 장벽을 낮춘다.

### 주요 요소

- 인사 메시지
- 거북이 일러스트 히어로 영역
- 집중 시간 프리셋 버튼
- 오늘의 응원 문구
- 친구 거북이 요약 카드

### 사용자 행동

1. 시간을 고른다.
2. 세션 시작 버튼을 누른다.

## 3. 집중 세션 화면

### 목적

- 사용자가 공부 중에도 안정감을 느끼게 한다.
- 타이머와 거북이 진행 상태를 한눈에 보여준다.

### 주요 요소

- 남은 시간
- 거북이와 산책로
- 현재 집중 상태 메시지
- 짧은 돌봄 모달 또는 카드
- 세션 포기 또는 종료 버튼

### 상태

- `idle`: 시작 전
- `walking`: 거북이 이동 중
- `care-needed`: 물 또는 당근 요청
- `cheerful`: 돌봄 직후 긍정 반응
- `completed`: 세션 완료

## 4. 돌봄 상호작용

### 목적

- 집중 흐름을 완전히 끊지 않으면서 감정적 연결을 만든다.

### 방식

- 세션 중간 한두 번만 등장
- 선택지는 단순하게 유지
- 응답 후 즉시 닫히고, 짧은 애니메이션만 남긴다

### 예시 문구

- `조금 목말라 보여요. 물 한 모금 줄까요?`
- `천천히 가고 있지만 잘하고 있어요. 당근을 줄까요?`

## 5. 세션 완료 화면

### 목적

- 집중 성공의 감정적 보상을 크게 전달한다.

### 주요 요소

- 완료 축하 메시지
- 거북이 애교 반응
- 오늘 걸은 거리 또는 누적 시간
- 다시 시작 버튼

### 기대 감정

- 수고했다
- 귀엽다
- 한 번 더 해볼까

## 6. 친구 거북이 보드

### 목적

- 소셜 동기를 가볍게 제공한다.

### 주요 요소

- 친구 거북이 카드 3~4개
- 오늘 집중 시간 또는 거리
- 짧은 상태 메시지

### 설계 원칙

- 랭킹보다 동행
- 승부보다 응원
- 초기에는 정적 데이터로 표현 가능

## 7. 비주얼 방향

- 크림, 세이지 그린, 살구빛 톤 중심
- 둥근 형태와 부드러운 그림자
- 종이 일러스트처럼 포근한 레이어감
- 느린 흔들림, 호흡, 걷기 애니메이션

## 8. 접근성과 사용성

- 타이머 숫자는 충분히 크게 보여준다.
- 색만으로 상태를 구분하지 않는다.
- 모바일에서는 엄지로 누르기 쉬운 버튼 크기를 유지한다.
- 애니메이션이 있어도 정보 읽기를 방해하지 않게 한다.
