# Turtle Study Design System

## Goal

이 문서는 Turtle Study의 시각 기준점을 고정한다.

이번 단계의 목표는 구현보다 먼저 아래를 레포 안에 확정하는 것이다.

- 메인 장면 톤
- 거북이 캐릭터 상태별 실루엣
- 컬러 팔레트
- UI 밀도와 표면 처리 방식
- 자산 파일 경로

이 문서는 첨부된 시안의 방향을 기준으로 한다.
핵심 키워드는 `따뜻함`, `파스텔`, `수채화 질감`, `천천히 걷는 안정감`, `귀여움`이다.

---

## Visual Principles

### 1. Scene First

- 화면의 주인공은 카드가 아니라 `풍경`과 `거북이`다.
- UI는 장면을 가리지 않는 오버레이 또는 가벼운 표면으로 올린다.
- 시작 전에도 풍경이 먼저 보여야 한다.

### 2. Soft Storybook Mood

- 채도는 낮고 명도는 높다.
- 강한 대비보다 은은한 겹침을 사용한다.
- 직선적인 디지털 그래픽보다 둥근 손그림 느낌을 우선한다.

### 3. Horizontal Journey

- 시간은 왼쪽에서 오른쪽으로 흐른다.
- 길은 가로형이 기본이다.
- 경로는 완전 직선이 아니라 완만하게 굽는다.

### 4. Gentle Companion

- 거북이는 작고 둥글며 위협감이 없어야 한다.
- 머리는 지금보다 더 작고, 몸과 껍질이 안정적으로 보여야 한다.
- 표정은 선명하지만 과장되지 않게 간다.

## Typography

- 제목은 둥글고 부드러운 인상의 산세리프를 유지한다.
- 본문은 과하게 얇지 않은 읽기 쉬운 폰트를 쓴다.
- 느낌은 `storybook UI`, `gentle app`, `paper label`에 가깝게 유지한다.

카피 톤:

- 압박형 문구 금지
- “빨리”, “성공”, “승리”보다 “천천히”, “같이”, “충분해”, “버텨냈어요”를 우선한다

## Surfaces

- 패널은 불투명 카드보다 `얇은 크림색 반투명 표면`을 쓴다.
- border는 선명한 회색 대신 아주 연한 따뜻한 톤을 쓴다.
- 그림자는 무겁지 않게 확산형으로 처리한다.

기본 표면 기준:

- 배경: `rgba(255, 252, 244, 0.82)`
- 보더: `rgba(255, 255, 255, 0.5)`
- 그림자: `0 16px 36px rgba(120, 117, 89, 0.12)`
- radius: `24px ~ 32px`

## UI Concept Lock

첨부 시안의 `UI CONCEPT`를 아래처럼 고정한다.

### 1. Time Selection Popup

- 시간 선택은 메인 카드가 아니라 `중앙 팝업`으로 연다.
- 팝업 구조는 아래 순서를 따른다.

1. 상단 제목: `집중할 시간을 선택해요`
2. 원형 또는 둥근 시간 버튼 5개
3. 하단 메인 CTA: `시작하기`
4. 모서리 장식 요소: 작은 꽃 또는 작은 거북이

레이아웃 규칙:

- 기본 폭: `320px ~ 420px`
- 제목과 시간 버튼 사이 여백은 넉넉하게 둔다
- 선택된 시간 버튼은 `leaf-400` 계열 포인트로 강조한다
- CTA는 한 눈에 보여야 하지만 과하게 두껍지 않게 간다

### 2. Focus HUD

- 세션 중 HUD는 `아주 작은 pill형 바`를 기본으로 한다.
- 정보는 최소 3개만 허용한다.

1. 작은 아이콘 또는 잎
2. 남은 시간
3. 일시정지 또는 재개 버튼

규칙:

- 화면의 주인공은 장면이므로 HUD가 시선을 빼앗으면 안 된다
- 기본 위치는 `상단 중앙 또는 하단 좌측`
- 말풍선보다 조용한 표면이어야 한다

### 3. Care Moments

- 물/당근 선택 UI는 큰 카드 대신 `작은 보조 패널` 또는 `둥근 아이콘 버튼 묶음`으로 간다.
- 패널은 길을 가리지 않는 위치에 둔다.
- 버튼은 `아이콘 + 짧은 레이블`로 충분하다.

### 4. Completion Tone

- 완료 후에도 장면을 지우지 않는다.
- 축하 카드는 장면 위에 가볍게 뜨되, 배경은 계속 보이게 유지한다.
- 반응은 요란한 승리감보다 `조용한 기쁨`을 우선한다.

## Motion

- 걷기 모션은 과장된 점프보다 `작은 상하 리듬 + 교차 보행`이 핵심이다.
- 몸통은 2~4px 수준으로 부드럽게 흔들린다.
- 머리는 한 박자 늦게 따라오며 안정감을 준다.
- 리듬은 급하지 않다.

걷기 수치 기준:

- 거북이 위치 이동은 `길 위 실제 좌표 이동`이 기본이다.
- 보행 프레임은 `2프레임 또는 3프레임` 정도면 충분하다.
- 몸통 상하 이동: `2px ~ 3px`
- 머리 상하 이동: `1px ~ 2px`
- 머리 좌우 회전: `0deg ~ 2deg`
- 위아래 bounce처럼 보이는 큰 점프 금지
- 한 걸음 리듬은 `0.7s ~ 0.95s`
- 전체 전진 속도는 타이머 진행률이 결정한다
- 캐릭터 애니메이션은 전진감을 보조할 뿐, 위치를 대신하면 안 된다

상태별 기준:

- `walking`: 차분한 교차 보행
- `resting`: 낮은 자세, 눈 감음, 거의 움직이지 않음
- `cheerful`: 머리 들기, 앞발 살짝 올리기, 표정 밝아짐

추가 규칙:

- `walking`에서도 머리와 몸통 과장 금지
- `resting`은 상하 움직임보다 호흡 같은 정적 리듬을 준다
- `cheerful`은 잠깐 밝아지되 실루엣은 유지한다

## Main Scene Composition

- 하늘은 연한 버터색에서 크림색으로 내려오는 그라데이션
- 뒤쪽 언덕 2~3 레이어
- 가운데 구불구불한 흙길
- 시작 표지판, 물그릇, 당근, 도착 깃발
- 작은 꽃, 덤불, 나무로 여백을 채움

구현 시 주의:

- 배경 장면은 장식이 아니라 제품의 중심 자산이다.
- 앞으로 구현에서는 CSS로 풍경을 흉내 내는 대신, 이 자산 기반으로 화면을 맞춘다.

## Character Assets

상태별 거북이 이미지를 별도 파일로 관리한다.

- `public/design-system/turtle-walking.svg`
- `public/design-system/turtle-resting.svg`
- `public/design-system/turtle-cheerful.svg`

기본 규칙:

- 몸 색은 따뜻한 크림 톤
- 껍질은 낮은 채도의 초록
- 눈은 작은 점 또는 짧은 곡선
- 입은 짧고 둥글게
- 표정 변화는 `눈/입/머리 각도` 중심으로 해결한다
- 걷는 중에도 전체 실루엣은 매 프레임 크게 바뀌지 않는다
- 귀여움은 큰 머리보다 `둥근 비율`, `작은 표정`, `안정된 자세`에서 만든다

## UI Asset Strategy

이 프로젝트의 디자인 자산은 아래 원칙으로 관리한다.

- 배경과 캐릭터는 우선 `SVG 이미지 자산`으로 저장한다.
- 구현은 이 자산을 배치하고 움직이는 쪽으로 맞춘다.
- CSS만으로 자산을 새로 그리려 하지 않는다.
- 시안 변경이 생기면 먼저 자산을 수정하고 그다음 UI를 수정한다.

아이콘 자산은 다음 스타일을 따른다.

- 잎, 물방울, 당근, 하트, 별 모두 파스텔 수채화 톤
- 굵은 외곽선보다 부드러운 면 처리
- 같은 radius와 같은 그림자 규칙을 공유한다

## First Implementation Scope

이 디자인 시스템을 바탕으로 다음 구현 단계에서 우선 적용할 것:
