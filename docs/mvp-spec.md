# MVP Spec

## 1. 제품 개요

Turtle Study App은 사용자의 집중 시간을 `거북이와 함께 걷는 경험`으로 바꾸는 웹 앱이다.

핵심은 시간을 재는 기능 자체가 아니라, 사용자가 세션을 버티는 동안 거북이도 함께 여정을 이어간다고 느끼게 만드는 것이다.

## 2. 문제 정의

기존 집중 앱은 보통 두 방향으로 나뉜다.

- 차단형: 앱 이탈을 막고 규율을 강조한다.
- 성과형: 기록, 랭킹, 수치 성장에 집중한다.

이 구조는 효율적이지만, 지치거나 불안한 사용자에게는 피로를 줄 수 있다.

이 앱은 다음 문제를 풀고자 한다.

- 집중 자체가 외롭고 건조하게 느껴진다.
- 공부를 시작해도 금방 마음이 흐트러진다.
- 압박형 앱은 잠깐 효과가 있어도 오래 쓰기 어렵다.

## 3. 제품 가설

사용자가 `내가 무언가를 키운다`보다 `누군가와 함께 버틴다`고 느끼면, 집중 세션의 감정적 지속성이 올라간다.

특히 거북이라는 캐릭터는 느리지만 꾸준한 공부의 상징으로 잘 작동한다.

## 4. 타깃 사용자

- 혼자 공부하는 시간이 많은 학생
- 포모도로류 앱은 써봤지만 오래 정착하지 못한 사용자
- 압박보다 위로와 동행에 반응하는 사용자
- 감성적인 캐릭터/일러스트 기반 서비스에 호감을 느끼는 사용자

## 5. 핵심 가치 제안

- 거북이가 사용자의 집중 시간을 함께 버틴다.
- 짧은 돌봄 상호작용으로 정서적 애착을 만든다.
- 세션 완료 후 보상 반응으로 작은 성취감을 준다.
- 경쟁보다 응원과 동행이 먼저인 제품 감성을 유지한다.

## 6. MVP 목표

이번 MVP의 목표는 다음 질문에 답하는 것이다.

1. 사용자가 거북이 동행 콘셉트를 매력적으로 느끼는가
2. 집중 흐름을 해치지 않으면서 돌봄 상호작용이 긍정적으로 작동하는가
3. 세션 완료 보상이 재사용 의도를 높이는가

## 7. 핵심 사용자 시나리오

1. 사용자가 홈 화면에서 집중 시간을 선택한다.
2. 세션을 시작하면 거북이가 길을 걷기 시작한다.
3. 세션 중간 짧은 시점에 물 또는 당근 돌봄 요청이 나타난다.
4. 사용자가 응답하면 거북이가 안정되거나 기뻐하는 반응을 보인다.
5. 세션이 끝나면 거북이가 애교를 부리며 보상을 제공한다.
6. 사용자는 오늘의 여정과 친구 거북이 현황을 가볍게 확인한다.

## 8. MVP 기능 범위

### 포함

- 집중 시간 프리셋 선택
- 집중 세션 시작/진행/완료 상태
- 거북이 이동 애니메이션
- 돌봄 인터랙션 1~2회
- 세션 완료 보상 카드
- 친구 거북이 보드의 정적 또는 준정적 UI

### 제외

- 로그인과 계정 저장
- 실제 친구 추가
- 실시간 경쟁
- 푸시 알림
- 결제 기능
- 복잡한 업적 시스템

## 9. 성공 기준

- 첫 방문 사용자가 제품 콘셉트를 10초 내 이해할 수 있다.
- 세션 시작까지의 클릭 수가 적다.
- 세션 진행 화면이 과하게 산만하지 않다.
- 완료 화면에서 다시 한 번 세션을 시작하고 싶다는 감정이 생긴다.

## 10. 위험 요소

- 돌봄 상호작용이 집중을 방해할 수 있다.
- 감성 표현이 약하면 흔한 타이머처럼 보일 수 있다.
- 소셜 요소가 과하면 따뜻한 브랜드 톤이 깨질 수 있다.

## 11. 설계 원칙

- 압박보다 동행
- 기능보다 감정선
- 과잉 게임화보다 잔잔한 애착
- 복잡한 시스템보다 이해 쉬운 흐름

## 12. 다음 단계

MVP 이후에는 아래 순서로 확장 가능하다.

1. 세션 기록 저장
2. 거북이 성장과 집 꾸미기
3. 친구 응원 기능
4. 가벼운 경쟁 모드
5. 모바일 앱 전환 검토
